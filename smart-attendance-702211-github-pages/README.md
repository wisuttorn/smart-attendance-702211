# Smart Attendance 702211

เว็บไซต์สำหรับ Business Finance 1 ที่เชื่อมกับสคีมา `smart_attendance` ใน Supabase โปรเจกต์ Finance Quest

## ก่อนเปิดใช้งาน

- ให้ผู้ดูแล Supabase ผูกวิชา 702211 กับ UUID ของบัญชีอาจารย์ใน Supabase Auth และเพิ่มกลุ่มเรียนใน `smart_attendance.sections` รหัสกลุ่มเรียนต้องตรงกับรายชื่อจริง
- ตั้ง GitHub Pages ให้ใช้ GitHub Actions แล้วอัปโหลดไฟล์ใน ZIP ไปยังสาขา `main` โดยเก็บโฟลเดอร์ `.github` ไว้
- Configuration ฝั่งเว็บมีเฉพาะ URL และ publishable key ของ Supabase

## นำเข้ารายชื่อ

บันทึกไฟล์จาก Excel เป็น CSV UTF-8 โดยใช้หัวคอลัมน์ `student_code,full_name` เปิดหน้าอาจารย์ เลือกกลุ่มเรียน แล้วอัปโหลดทีละกลุ่ม ระบบรองรับสูงสุด 500 แถวต่อครั้ง ตั้งคอลัมน์รหัสนักศึกษาเป็นข้อความเพื่อรักษาเลขศูนย์นำหน้า อย่าอัปโหลดไฟล์รายชื่อเข้า GitHub

ให้อาจารย์ส่งลิงก์เปิดใช้งานบัญชีและ Activation Code ของแต่ละคนให้เจ้าตัวโดยตรง รหัสใช้ได้ครั้งเดียวภายในเจ็ดวัน นักศึกษาจะตั้ง PIN 6 หลักเมื่อเปิดใช้งาน

## ทดสอบบน URL ที่เผยแพร่

1. เปิดคาบจากหน้าอาจารย์ แล้วเปิดหน้าจอโปรเจกเตอร์
2. ใช้มือถือสแกน QR กับบัญชีทดสอบและยืนยันด้วย PIN ตรวจว่าชื่อปรากฏฝั่งขวา
3. รอให้ QR เปลี่ยนและลองเปิด QR เก่า ตรวจว่าประมวลผลเฉพาะ QR ใหม่
4. สแกนใหม่ด้วยนักศึกษาคนเดิม ตรวจว่ามีชื่อเพียงหนึ่งรายการ
5. ปิดคาบจากหน้าอาจารย์ ตรวจว่าการเช็กอินหยุดและจอโปรเจกเตอร์ซ่อน QR
